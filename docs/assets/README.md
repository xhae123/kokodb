## Rebuild

Brand geometry is generated by `brand.py` using the Python standard library. The chart renderer uses Python and Matplotlib (qualified with 3.9.4). It reads the checked-in CSVs; it does not rerun benchmarks or fetch network data.

```sh
python3 -m venv .local/figures-venv
.local/figures-venv/bin/pip install matplotlib==3.9.4
.local/figures-venv/bin/python docs/assets/render.py
```

SVG is the editable source representation, with text retained as text and portable sans-serif fallbacks. The mark is custom path geometry, not a font glyph. Chart PNGs come from the same plotting code. Brand PNGs are transparent 2x browser exports (512×512 marks, 1000×320 wordmark). Rebuild those after editing the brand SVGs using Node.js and Chromium/Chrome:

```sh
node docs/assets/export-brand.mjs "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

Pass the browser executable path for your platform. The exporter uses a temporary profile and does not read an existing browser session. Qualified locally with Node.js 24.4.1 and Chrome on macOS. Font rasterization can differ by platform; the SVG geometry remains authoritative. No external font, linked image, JavaScript or tracking resource is embedded. When embedding a comparison figure, include its workload, measurement boundary and report link alongside descriptive alt text.

Inspect both desktop and 375-pixel mobile rendering after edits. The initial review caught a footer/axis overlap and a missing-font serif fallback; spacing and font stacks were corrected before the final preview. Raw local renders and checks are retained under `.local/improvements/2026-10-23-readme-research/`.

## Identity

The two folded bands form a K with a horizontal gap. Preserve that gap at small sizes. Use the solid violet primary mark on light surfaces and the white variant on dark surfaces. The accent is `#7C3AED`; the optional icon tile uses `#251044`.

The README header contains only the logo and name. Keep introductory copy in Markdown so it wraps naturally, and do not add a gradient panel, decorative shapes, pills or duplicate project title. H2 retains its comparison blue in charts.
